클립메모 개인정보처리방침

시행일: 2026년 10월 7일

클립메모(이하 "앱")는 메모를 이용자 본인의 구글 드라이브에 저장하는 메모장입니다. 앱 개발자는 이용자의 메모를 보관하는 서버를 운영하지 않으며, 메모 내용을 수집하거나 전송받지 않습니다.

1. 처리하는 정보와 목적

정보어디서·어떻게목적
구글 계정 이메일·이름·프로필 사진구글 로그인으로 받아 기기에만 저장로그인, 계정 표시
메모(제목·본문·체크리스트·태그·색·알람), 사진, 첨부 파일, 손글씨기기에 저장하고 이용자 본인의 구글 드라이브 '클립메모' 폴더에 동기화메모 기능, 여러 기기 동기화
위치 (위치 알람을 켠 경우만)이 휴대폰의 현재 위치는 기기 안에서만 확인하고 외부로 보내지 않음. 장소를 고를 때의 검색어와 지도 위치는 아래 3항의 장소 검색 서비스로 보냄정한 장소에 도착·출발 알림
음성 (받아쓰기를 쓸 때만)녹음 파일을 만들지 않음. 기기의 음성 인식 기능이 처리하며, 설정에서 인터넷 인식을 고르면 구글 음성 인식 서비스가 처리말을 글로 바꾸기
사진 속 글자기기 안에서 인식 — Android는 구글 Play 서비스의 글자 인식기(처음 한 번 인식기를 내려받음), Windows는 Windows 내장 글자 인식. 사진은 기기 밖으로 보내지 않음사진 속 글자 검색
전화번호 (메모에 전화번호를 넣을 때만)폰: 기본 연락처 고르기 화면에서 이용자가 고른 한 사람의 이름·번호만 받음(주소록 전체를 읽지 않음). PC: '구글 주소록에서 찾기'를 쓰면 이용자의 구글 주소록을 읽기 전용으로 검색해, 이용자가 고른 이름·번호만 받음. 어느 쪽이든 주소록을 저장하거나 보내지 않으며, 고른 이름·번호는 메모 글로 들어가 메모와 같이 보관됨메모에 전화번호 넣기, 폰에서 전화·문자 앱 열기(거는 것·보내는 것은 이용자가 직접)
캘린더 일정 (구글 캘린더 연동을 켠 경우만)앱이 만든 '클립메모' 캘린더에만 알람 일정을 쓰고 읽음알람을 캘린더에 표시

앱은 광고를 표시하지 않으며, 광고 식별자·사용 통계·위치 기록을 수집하지 않습니다.

2. 구글 드라이브·캘린더·주소록 권한

  • 드라이브는 drive.file 권한만 씁니다. 앱이 만들거나 이용자가 앱에서 연 파일에만 접근하며, 드라이브의 다른 파일은 볼 수 없습니다.
  • 캘린더는 앱이 만든 캘린더에만 접근하는 권한을 씁니다(연동을 켤 때만 요청).
  • 주소록은 PC에서 '구글 주소록에서 찾기'를 처음 쓸 때만 읽기 전용 권한(contacts.readonly)을 요청합니다. 검색 결과 중 이용자가 고른 이름·번호만 메모에 넣고, 주소록은 저장하지 않습니다.
  • 구글 API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 이 정보는 위 기능에만 쓰며 제3자에게 제공하거나 판매하지 않습니다.

3. 외부 서비스

앱의 기능을 위해 다음 서비스와 통신합니다. 각 서비스의 개인정보 처리는 해당 회사의 방침을 따릅니다.

  • Google (드라이브, 캘린더, 주소록, 로그인, 음성 인식, 주소 검색, Play 서비스 글자 인식) — 메모 저장·동기화, 로그인, 받아쓰기(인터넷 인식을 고른 경우), 위치 알람의 장소 검색(휴대폰 내장 주소 검색), PC에서 전화번호를 넣을 때 주소록 검색(선택), Android 글자 인식기 내려받기
  • OpenStreetMap — 위치 알람에서 장소를 고를 때 지도 이미지를 받아 옴(이때 보고 있는 지도 영역이 요청됨). PC에서 장소를 검색하면 검색어와 지도 가운데 위치를 OpenStreetMap 주소 검색(Nominatim)으로 보냄
  • 카카오(카카오맵 로컬 API) — 위치 알람에서 지도 가운데가 한국일 때 장소 검색: 검색어와 지도 가운데 위치를 보내 주소·장소의 좌표와 이름을 받아 옴(메모 내용·계정 정보는 보내지 않음)
  • GitHub(구글 글꼴 저장소) — 설정에서 글꼴을 내려받을 때 글꼴 파일만 받아 옴(메모 내용은 보내지 않음)
  • GitHub(클립메모 릴리스) — 새 버전이 나왔는지 하루 두 번 이하로 최신 버전 번호를 읽어 옴(메모 내용·계정 정보는 보내지 않음)
  • 웹 뷰어(선택) — 브라우저에서 웹 뷰어에 로그인하면 브라우저가 이용자의 구글 드라이브에서 메모를 직접 읽어 보여 줍니다(읽기 전용). 메모는 그 창의 메모리에만 두고 브라우저에 저장하지 않으며, 개발자에게 보내지 않습니다. 화면 표시용 공개 라이브러리는 cdnjs(Cloudflare)에서 받아 옵니다.
  • 공유 링크 — 이용자가 공유 링크를 만들면 해당 메모의 사본이 이용자 드라이브에 구글 문서로 만들어지고, 링크를 가진 사람이 볼 수 있습니다. 링크는 앱에서 언제든 끌 수 있습니다.

4. 보관과 삭제

  • 메모는 이용자가 지울 때까지 기기와 이용자의 구글 드라이브에 남습니다.
  • 앱에서 메모를 지우면 휴지통을 거쳐 기기와 드라이브에서 지워집니다.
  • 앱을 삭제해도 드라이브의 '클립메모' 폴더는 남습니다. 구글 드라이브에서 폴더를 지우면 모든 메모가 지워집니다.
  • 잠금 메모는 이용자 비밀번호로 암호화되어 저장되며, 비밀번호를 잊으면 개발자도 복구할 수 없습니다.

5. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
